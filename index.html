Data and privacy

Control the local demonstration

Data is stored locally in this browser using localStorage where available. There is no server, login, automatic outreach, or cloud synchronization.

Use fictional or non-sensitive data in this prototype. Browser storage is not a secure, backed-up customer database and can be cleared.

Install on your device

Open from localhost on this computer or from an HTTPS site. In Chrome/Edge, use Install when offered; on iPhone, open in Safari and select Share → Add to Home Screen. Opening an HTML file directly does not enable installation or offline caching.

After the first online visit, the app shell works offline on the same device. Changes stay in this browser and are not synchronized or backed up.
