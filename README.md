# EstimateFollow public demo

This is a **fictional-data-only** prototype for testing contractor estimate follow-up. It is not suitable for storing real customer information.

- The app stores entries in local browser storage. There is no cloud database, account, telemetry, or automatic outreach.
- Messages are drafts that users must choose to send themselves.
- Volunteers should use fictional information only.
- For installation on a phone, open the HTTPS GitHub Pages URL, then use Add to Home Screen / Install.
- A guided five-minute test is included. Feedback must be voluntarily exported and shared; it is not collected automatically.

This public repository contains demo files only; no financial ledger or private business documents.

## Verification gate

Five consenting qualified contractors: at least four should complete the five-minute guided test without help, and at least two should explicitly want to try a secure pilot. If not, revise or pivot before adding paid features.

Source version: v0.3.2, public deployment assets adapted to a single SVG icon for text-based publishing. Real-phone installation and offline reload must still be tested.
